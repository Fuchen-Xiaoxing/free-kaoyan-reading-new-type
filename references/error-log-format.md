## 一、13 类错误类型与新题型 12 大死刑判据映射（封闭枚举）

### 13 类错误类型封闭枚举（`error_type` 字段必须严格属于此集合）
1. **定位错误** —— 定位位置选错、人名有效发言辐射区间划错
2. **无对应内容** —— 脱离核心论域/外来异物入侵，选项在原文对应位置无出处或无同义替换
3. **过度推理** —— 有一说二，根据原文断言脑补引申出未提及的常识或观点
4. **偷换概念/嫁接** —— 孪生选项鉴别失误（动词同义但宾语偷换）、主体偷换、概念嫁接
5. **因果倒置** —— 因果逻辑颠倒、时序前后错位
6. **态度背离** —— 正负极性判断错误，选了与建议或发言态度相悖的选项
7. **细节背离主旨** —— 细节陷入/反客为主，误把段落铺垫、案例细节或展开好处当成全段小标题
8. **绝对化误选** —— 选了含 only / must / never / all / 最高级等绝对化词汇的极端选项
9. **审题不清** —— 论域天花板越界/以偏概全，混淆讨论范畴或主体归属
10. **比较/时态偷换** —— 原文无比较而选项强加比较、时态不一致
11. **词义误解** —— 核心动词、受体名词或态度色彩不认识或理解错误
12. **长难句误读** —— 核心建议句/发言题眼句语法结构拆错，导致理解偏差
13. **选项误读** —— 选项看反意思、漏看否定、孪生干扰项粗心误判

---

### 新题型 12 大死刑判据 ↔ 13 类错误类型快速映射对照表

| 新题型 12 大死刑判据 | 对应错题本主 `error_type` | 典型命题陷阱与考场场景 |
| :--- | :--- | :--- |
| **判据一：无对应内容排除** | **无对应内容** | 选项核心实体脱离段落论域天花板，属于外来异物入侵 |
| **判据二：不合理与常识荒谬排除** | **无对应内容** / **选项误读** | 违背生活常理或策论常识（如“取消全部考核”） |
| **判据三：正负态度反向排除** | **态度背离** | 文章提出解决对策（+），误选了批判性痛点选项（−） |
| **判据四：主体混淆/张冠李戴排除** | **定位错误** / **审题不清** | 多项对应中将 A 学者的观点误安在 B 学者头上 |
| **判据五：因果倒置/逻辑时态颠倒** | **因果倒置** / **比较/时态偷换** | 将原因当作结果，或将过去历史当成现行建议 |
| **判据六：偷换概念/局部词形嫁接** | **偷换概念/嫁接** | 拼凑原文碎片单词，核心谓语动词或宾语被篡改 |
| **判据七：过度推理/脑补引申排除** | **过度推理** | “有一说二”，凭中文常识主观引申未提及的深层含义 |
| **判据八：绝对化/极端词误选排除** | **绝对化误选** | 选项出现 only, never, absolutely 等极端武断词 |
| **判据九：细节陷入/反客为主排除** | **细节背离主旨** | 误把末尾举例、数据细节或副产品当成全段主旨小标题 |
| **判据十：论域天花板越界/以偏概全** | **审题不清** / **无对应内容** | 小标题覆盖面过宽（宏观大而无当）或过窄 |
| **判据十一：孪生选项鉴别失误** | **偷换概念/嫁接** / **选项误读** | 动词一致但宾语偷换，或宾语一致但动词偷换 |
| **判据十二：原词重现陷阱排除** | **偷换概念/嫁接** / **细节背离主旨** | 原文孤立生词高频重现，但句子主干逻辑完全无关 |

### 能力短板三件套（封闭集合）
- **词汇**：核心动词、受体名词未掌握或极性色彩判断失误
- **语法**：题眼建议句、发言长难句结构分析失败
- **主旨**：论域天花板识别失败、建议范式判断失误、信息检索与拓扑对齐操作失误

## 二、存储位置与写入原则

- **存储文件与路径**：`新题型错题本.md` 默认安全持久化存储于 **Android 手机公共文档目录**（优先 Open Minis 挂载外部文档 `/var/minis/mounts/Documents/考研英语/新题型错题本.md` 或系统公共文档 `/storage/emulated/0/Documents/考研英语/新题型错题本.md`，支持通过 Obsidian、WPS 或系统文件管理器直接复习；未挂载外部目录时安全保存在沙箱工作区 `/var/minis/workspace/新题型错题本.md`），与传统阅读错题本独立分离，彻底与 Skill 目录解耦；更新、重新克隆或重装 Skill 绝不丢失历史数据。支持环境变量 `KAOYAN_NEW_TYPE_ERROR_NOTEBOOK` 或 `KAOYAN_ERROR_NOTEBOOK` 自定义指定（带路径自愈纠偏）。
- **写入规则**：**只追加、不覆盖、不修改历史条目**。一律通过 `scripts/record_error.py` 写入（自动清理占位符与安全迁移旧数据），禁止手工拼写。
- **定位与边界**：新题型错题本仅用于篇末归档沉淀与自主复习，日常讲解过程中不主动查阅、检索或关联历史错题。

## 三、条目 Schema (YAML frontmatter + 正文)

```markdown
---
id: 2025-新题型-Q41
刷次: 一刷
题型: 小标题匹配
error_type: 细节背离主旨
secondary_error_types: [无对应内容]
user_answer: C
correct_answer: A
能力短板: 主旨
解题关键词: Champion your idea
原文定位: Para 1 L3-5
错误还原: 误把段落末尾例子里的调查数据当成全段小标题
方法论归因: 违背“例子必定为主题服务，例子和好处全划掉，前置指令才是主旨”
教训金句: 抓转折后建议句，例子细节一票否决
---

### 2025-新题型-Q41

正文：详细的错误分析与复盘，用新题型方法论术语展开。
```

## 四、字段说明与约束

| 字段名 | 必填 | 取值约束与说明 |
| :--- | :---: | :--- |
| `id` | 是 | 统一标准规范 ID：`YYYY-新题型-Q[41-45]`（如 `2025-新题型-Q41`；重复时脚本自动追加 `-2`, `-3`，自动纠偏 `PartB` 等变体） |
| `刷次` / `round` | 否 | 默认 `一刷`。若用户在对话中说明是二刷/三刷，则记录为 `二刷`/`三刷` |
| `题型` / `question_type` | 是 | **小标题匹配** / **多项对应**（或排序题 / 七选五） |
| `error_type` | 是 | **必须严格属于上述 13 类错误类型封闭枚举之一**（主错误类型） |
| `secondary_error_types` | 否 | 副错误类型列表（数组，值必须属于 13 类枚举之一，记录复合错误） |
| `user_answer` | 否 | 用户选择的选项（如 `C`） |
| `correct_answer` | 否 | 正确选项（如 `A`） |
| `能力短板` / `ability_shortboard` | 是 | **必须严格属于 {词汇, 语法, 主旨} 封闭集合之一** |
| `解题关键词` / `keyword` | 是 | 题干定位词、核心人名或段落建议切入点 |
| `原文定位` / `location` | 是 | 定位句出处（如 `Para 2 L3-4`） |
| `错误还原` / `restore` | 是 | 以错题复盘中用户自述思路 + 诊断出的思维误区为准，真实记录，禁止凭空编造 |
| `方法论归因` / `attribution` | 是 | 违背或忽略的新题型方法论原则（如论域天花板、建议句雷达、语义指纹等） |
| `教训金句` / `lesson` | 是 | 一句话前瞻教训与应对解法 |
| `正文` / `analysis` | 是 | 详细的错误分析与复盘 |
